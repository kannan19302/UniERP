# Enterprise capability audit

Read the [workspace entrypoint](../../../../../AGENTS.md),
[enterprise brain](../../../governance/skills/unierp-enterprise-brain/SKILL.md), and
[governance evidence guidance](../../governance/ENTERPRISE_SAAS_GOVERNANCE.md).

1. Define the requested capabilities and acceptance criteria. Locate their owning platform requirements,
   published contracts, implementation and matching boundary evidence.
2. Classify each finding as implemented with proof, partial, declared, unverified, gap or not applicable using
   the documentation authority's vocabulary. Record owners and evidence, not invented percentages.
3. Treat the [capability ideas](../../knowledge/SALESFORCE_OVERTAKE_KNOWLEDGE_BASE.md) as proposals. Verify any
   competitor claims with dated primary sources before using them; do not convert them into product requirements.
4. Inspect the runner at platform/workspace/scripts/run-enterprise-saas-engine.mjs before executing it. Its
   inventory, flags and side effects must match the task. Do not infer real benchmark or remediation behavior
   from a command name. Prefer focused repository checks with recorded results.
5. Remediate only authorized findings, in dependency order. Use the
   [workflow](../../workflow/ENTERPRISE_SAAS_WORKFLOW.md) and canonical completion predicates.
6. Report actionable gaps and remaining work. No automatic commit, push, external contact, deployment or
   unbounded workspace-wide remediation is authorized by this skill.
