# Selected screen sequence

Open index.html for a searchable visual gallery. SCREEN_MANIFEST.json is the selected-image index. DP-001–DP-108 are the final journey order; originId preserves the former numbering. The first76 historical IDs are consolidated originals, not necessarily the first76 in the new journey order.

The PNGs are high-fidelity concepts with synthetic sample content. Implement using approved Strata tokens and components, not raster sampling. Written requirements, accepted architecture and state contracts govern semantics where sample image text is abbreviated or ambiguous. Prototype imagery does not establish real service status or accessible DOM behavior.
