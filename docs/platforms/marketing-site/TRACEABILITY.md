## Visual accessibility evidence updates

### MAR-UX-004 / AC-77 contrast evidence — 2026-09-25

The public homepage, pricing, and contact hero copy and active actions were sampled in production-browser screenshots in both themes: 30 text/action pairs passed their WCAG 2.2 AA size-specific contrast thresholds. The minimum measured ratio was 12.17:1. The light-theme homepage kicker previously used `#1d4ed8` against a sampled `#0f172a` hero pixel (2.66:1); its shared style now mixes the terminal text color with the theme accent and retests at 12.89:1. Screenshot and per-pair evidence: `marketing-site/.agents/marketing-hero-contrast-validation-2026-09-25.json` and its six referenced screenshots. This is representative desktop evidence only; MAR-UX-004 stays PARTIAL because other text, overlay/image intersections, all routes, mobile and assistive-technology behavior remain unverified.

### MAR-UX-004 / AC-78 brand consistency — 2026-09-25

All 57 sitemap route responses contain the shared accessible header and footer brand links and both theme wordmark assets; all six brand/favicon endpoints return HTTP 200. Chrome 153 confirmed the header, footer, and mobile navigation dialog switch between the design-system light/dark wordmarks together at 390×844 CSS pixels. The six public SVG copies match the design-system source by SHA-256. Evidence: `marketing-site/.agents/marketing-brand-validation-2026-09-25.json`. MAR-UX-004 remains PARTIAL pending broader visual, route-interaction, and assistive-technology review.

### MAR-UX-004 / AC-79 administration brand consistency — 2026-09-25

The admin shell uses the supplied horizontal wordmark when expanded, the supplied glyph when collapsed, and the wordmark on its OIDC login interstitial. Admin icon metadata uses the approved UniERP favicon set, and the root not-found page now has a theme-aware wordmark and accessible home link. A 120-route production build passed; `/admin/login` returned HTTP 200 with the brand and favicon markup; the custom 404 returned HTTP 404 and passed dark-theme browser visual/accessibility-tree inspection with both theme images loaded. All six copied SVGs match the design-system source by SHA-256. The authenticated admin sidebar theme states remain unverified because no approved QA session was available; authentication was not bypassed. Evidence: `marketing-site/.agents/marketing-admin-brand-validation-2026-09-25.json`. This scoped branding proof does not close broader visual, route-interaction, or assistive-technology gaps in MAR-UX-004.
