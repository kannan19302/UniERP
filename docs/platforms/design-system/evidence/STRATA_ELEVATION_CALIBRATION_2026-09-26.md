- Input: preserved caller `aria-invalid`, added semantic focus, read-only, forced-colour and reduced-motion treatment; removed extra disabled opacity after the live dark-theme contrast finding; large control follows the density control token; stories now label and describe states, include read-only and reflow the gallery.
- DataTable: keyboard row activation, distinct selection names, named keyboard-reachable scroll area, `aria-busy`, visible focus and sort/selection status; story and unit assertions added. Existing controlled selection and sort contracts remain.
- Breadcrumb: callback ancestor is a native button, unlinked terminal item is static with `aria-current=page`, existing terminal links remain navigable for compatibility, and repeated breadcrumb landmarks take distinct labels after the live axe finding. Link/button focus is visible, long paths wrap with logical CSS; story and unit assertions added.
- Storybook build was repaired after detecting stale relative imports from the wider in-progress FactBox and foundation moves. No independent component was created.
